# fn (deprecated)

> **Warning:** `fn` is deprecated and no longer compiles. It is **not** the
> function keyword in Mojo 1.x. Every occurrence of `fn` in old code or old
> tutorials is a pre-1.0 spelling — replace it with [`def`](def.md). This page
> deliberately teaches nothing about `fn` usage.

`fn` was unified into `def` in Mojo 1.0 and is deprecated; write
[`def`](def.md) for every function declaration. The migration is recorded in
[`versions/1.0.0`](../versions/1.0.0.md).

Exact official status in 1.0.0b2: "The legacy `fn` keyword now produces an error
instead of a warning. Please move to `def`."
(<https://mojolang.org/releases/v1.0.0b2/>)
